# ブリーフ: 服用の履歴を一覧で見返せるようにする

- **プロジェクト**: `/Users/kakeru/Dev/4_アプリ/KusuriLogWeb`
- **委任設定**: effort=`high` / model=既定

## 狙い

本人（2026-10-18）「薬をのんでボタンを完了にするわけだけど、それをいつ飲んだか見直せない。致命的です。履歴を見返せるようにしないとあかん」。

今も記録には実際に押した時刻（`doseLogs[].completedAt`）が残っていて、「今日」の画面で「前の日」を押せば 1 日ずつは見られる。しかし「この薬を最後にいつ飲んだか」「この 1 週間ちゃんと飲めたか」を見るには、1 日ずつさかのぼるしかない。**服用の記録を、新しい順の一覧でまとめて見返せる**ようにする。押し忘れて後から押したときに、飲んだ時刻を直せるようにもする。

## 作るもの（WHAT）

### 1. 「経過」タブに「服用の記録」
- 「経過」タブの一番上に、`体調`・`服用` の切り替え（既存の `segmented` の見た目）を置く。初期は今までどおり `体調`（今の「体調の推移」と「記録」がそのまま出る）
- `服用` を選ぶと、服用の記録（`doseLogs` のうち `status` が `taken` か `skipped` のもの。定時薬と頓服薬の両方）を**日付の新しい順**に、日ごとの見出しを付けて並べる
  - 見出し: `10月18日（土）` の形。その日の定時薬の数を `3 / 4 回` のように添える（その日に予定されていた回数に対して、服用済みにした回数。頓服は数えない）
  - 1 行: **飲んだ時刻**（`completedAt` の時刻）・薬の名前・1 回量・種類（定時なら `予定 8:00`、頓服なら `頓服`）・状態（`服用` / `見送り`）
  - 予定の日と記録した日が違う（後から押した）ときは、今の `takenText()` と同じように、記録した日付も出す
- 薬で絞り込める（`すべて` と、記録のある薬の名前の選択肢）。絞り込むと、その薬の記録だけになる
- 最初は直近 14 日分を出し、末尾の `もっと見る` で 14 日ずつさかのぼる
- 記録が 1 件もないときは、既存の `empty()` の形で「服用の記録はまだありません」

### 2. 記録の時刻を直す
- 一覧の行を押すと、既存の編集ダイアログ（`#editor`）で、その記録の**飲んだ日時**（`datetime-local`）と状態（服用 / 見送り）を直せる。保存で `completedAt` と `status` を書き換える
- 状態を `服用` ↔ `見送り` に変えたときの残量（`stock`）の増減は、今の「取り消す」→「服用した」と同じ結果になるようにする（二重に減らさない・戻しすぎない）
- ダイアログに `この記録を消す` を置く。動きは今の「取り消す」と同じ（残量を戻す）
- 直した結果は、「今日」の画面のその日の表示にもそのまま反映される

## 不可侵

- 保存キー `kusuri-log-web-v1` とデータの形。新しい項目を足す必要があれば `normalizeStore()` で旧データに既定値を補う。既存データを初期化・上書きしない
- 今の「今日」の画面（前の日・次の日・服用した・見送る・取り消す）、「薬」「通院」「設定」タブ、体調の推移のグラフ、バックアップ・復元の形式
- 判断・推奨・助言をしない（「飲み忘れています」などの注意や、飲む量の提案を出さない。記録の事実だけを並べる）
- `sw.js` は、変更したファイルがキャッシュされるならキャッシュ名を上げる
- push しない（公開は本人の確認後に Claude が行う）

- iPhone 版（`../KusuriLog`）

## 受け入れ条件

作り物のデータ（定時薬 2 種 × 1 日 2 回・頓服 1 種で 20 日分、見送り・後から押した記録・取り消した記録を含む）をテストで `localStorage` に入れて確かめる。実データは使わない。

- [ ] 「経過」タブを開くと、今までどおり体調の推移が出る。`服用` に切り替えると、記録が新しい日付順・日ごとの見出し付きで出て、各行に飲んだ時刻・名前・量・`予定 8:00` か `頓服`・状態が出る
- [ ] 見出しの `n / m 回` が、その日の予定回数と服用済みの数に一致する
- [ ] 後から押した記録（予定日 10/17・記録 10/18 9:00）は、10/17 の見出しの下に、記録日が分かる形で出る
- [ ] 薬で絞り込むと、その薬の記録だけになる。`すべて` で戻る
- [ ] 最初は 14 日分で、`もっと見る` で 28 日分になる。それ以上記録がなければ `もっと見る` は出ない

- [ ] 旧形式のデータ（この変更の前の `kusuri-log-web-v1`）を読み込んでもエラーにならず、既存の記録がそのまま出る
- [ ] 幅 390px で横にはみ出さない。ライト・ダークの両方で読める
- [ ] `node --check app.js` と `git diff --check` が通る
