# くすりログ Web版

端末内保存の服薬・通院記録PWA

| 項目 | 内容 |

| 状態 | 使える |

| 公開 | 公開（https://kk-corder.github.io/kusuri-log-web/） |

## 何か

サーバーやアカウントを使わず、入力内容をブラウザの端末内ストレージへ保存するPWAです。薬や症状について判断・助言は行いません。

### 主な機能

- 時刻を指定する定時薬と、必要時に記録する頓服薬
- 服用記録と薬の残量
- 通院・診察メモ・次回TODO
- 過去の通院履歴から病院名を候補表示
- 通院日と処方された薬の紐付け
- 診察料金、処方薬料金、合計金額
- 症状経過の日記
- JSONバックアップ・復元

### プライバシー

- 入力した薬、病院、服用履歴、症状、メモはブラウザの端末内ストレージにだけ保存します。
- アクセス解析、広告、ユーザーアカウント、独自サーバーへのデータ送信はありません。
- Googleカレンダーはユーザーが追加ボタンを押した場合だけ開き、病院名と日時を予定作成画面へ渡します。
- 公開リポジトリにはアプリのソースコードだけを置き、利用者が入力したデータは含まれません。

## 使い方

公開URLを Safari で開き、ホーム画面へ追加するとアプリに近い表示で起動できます。iPhoneで使うにはHTTPSで配信する必要があります。

### 注意

- Safariのサイトデータを消すと記録も消えるため、設定画面から定期的にバックアップしてください。
- JSONバックアップは暗号化されていません。
- Web版では時刻通知を主要機能として保証しません。

## 構成

```text
index.html / styles.css / app.js   画面・見た目・動作（記録は localStorage の kusuri-log-web-v1）
manifest.webmanifest / sw.js       ホーム画面への追加とオフライン表示
icons/                             アプリのアイコン
tests/                             Node のテスト
AGENTS.md・CLAUDE.md・_TODO.md     開発のルール・入口・タスク
docs/briefs/・docs/reports/        Codex へのブリーフと実装報告
```

## 開発と検証

ルールは `AGENTS.md`（保存キー `kusuri-log-web-v1` を変えない・既存データを消さない、など）。

```bash
python3 -m http.server 8080   # Dev/4_アプリ で実行し、http://localhost:8080/KusuriLogWeb/ を開く
node --test tests/
```
